# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues for
`PyGuDev/messenger`. Use the `gh` CLI for issue operations and infer the
repository from the `origin` remote.

## Conventions

- Publishing a spec means creating a GitHub issue.
- Multi-line issue bodies should be supplied from a reviewed Markdown file.
- Pull requests are not treated as an issue-triage request surface.
- Read an issue with its comments and labels before updating it.
- Preserve GitHub's shared issue/PR number space when resolving a bare number.
